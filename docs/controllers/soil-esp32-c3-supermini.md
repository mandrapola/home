# Выносной контроллер почвы (ESP32-C3 SuperMini)

## Статус
В текущем дереве `client/controller/` отдельного скетча для ESP32-C3 SuperMini нет. Раздел описывает планируемый/внешний контроллер и не является зафиксированной распиновкой существующей прошивки.

## Назначение
- `soil_moisture_raw` -> сырое ADC-значение влажности почвы
- `soil_temperature` -> температура почвы, опционально

## Примечания
- Контроллер почвы отправляет данные напрямую на сервер по Wi-Fi и регистрируется как отдельный контроллер пользователя.
- Сценарии могут использовать его датчики для управления реле основного Uno-контроллера.
- Калибровка влажности почвы хранится только на сервере в настройках пина.
- ESP32-C3 не хранит `dry/wet` калибровку и не отправляет проценты как основной источник данных.
- Локальные страницы должны повторять подход ESP8266: `/local`, `/status`, `/config`, fallback AP, Basic Auth, `config.txt` и `ca.pem` в LittleFS.
