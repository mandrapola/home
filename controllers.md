# Конфигурации Контроллеров

## Контроллер Теплицы (Arduino Uno + Ethernet Shield)

### Фиксированная распиновка
- `D10` -> Ethernet Shield `SS` (служебный, не использовать для других устройств)
- `D11` -> Ethernet Shield `MOSI`
- `D12` -> Ethernet Shield `MISO`
- `D13` -> Ethernet Shield `SCK`
- `D2` -> `DHT22 DATA`
- `D3` -> `Реле 1`
- `D5` -> `Реле 3`
- `D6` -> `Реле 4`
- `D9` -> `Реле 2`
- `D7` -> `TM1637 DIO` (опционально, сейчас не установлен)
- `D8` -> `TM1637 CLK` (опционально, сейчас не установлен)

### Линии питания
- `5V` -> `DHT22 VCC`, `Relay VCC`, `TM1637 VCC`
- `GND` -> общая земля всех модулей

### Свободные порты для расширения
- Цифровые GPIO:
  - `D7`, `D8` (свободны, пока TM1637 не подключен)
  - `D4` (рекомендуется как резерв; часто используется как `SD_CS` в связке Ethernet Shield/SD)
- Аналоговые GPIO:
  - `A0`, `A1`, `A2`, `A3`

### Примечания
- `D10..D13` держать выделенными под SPI Ethernet.
- `D4` держать как служебный/резервный пин для совместимости с SD chip-select.
- Для всех устройств обязательна общая земля (`GND`).

### Ключи телеметрии (поле `readings[].pin`)
- `air_temperature` -> температура воздуха с `DHT22` (`D2`)
- `air_humidity` -> влажность воздуха с `DHT22` (`D2`)
- `relay_1` -> фактическое состояние выхода `D3`
- `relay_2` -> фактическое состояние выхода `D9`
- `relay_3` -> фактическое состояние выхода `D5`
- `relay_4` -> фактическое состояние выхода `D6`
- `soil_moisture_raw` -> сырое значение `A0`
- `light_level_raw` -> сырое значение `A1`
- `tank_level_raw` -> сырое значение `A2`
- `water_pressure_raw` -> сырое значение `A3`
- `analog_spare_1_raw` -> сырое значение `A4`
- `analog_spare_2_raw` -> сырое значение `A5`

## Контроллер Метеостанции (ESP32)

### Назначение
Измерение параметров окружающей среды и водной системы в составе общего узла метеостанции.

### Рекомендуемые датчики
- Температура воздуха + влажность воздуха + атмосферное давление: `BME280` (I2C)
- Факт дождя (бинарно): модуль датчика дождя `DO`
- Количество осадков: rain gauge с опрокидывающимся ковшом (импульсный выход)
- Скорость ветра: анемометр (импульсный выход)
- Направление ветра: флюгер (аналоговый выход)
- Температура воды в баке: `DS18B20` (OneWire)
- Уровень освещенности: `BH1750` (I2C)
- Давление в водопроводе: аналоговый датчик давления (`0.5..4.5V`, обычно через делитель/буфер под диапазон ADC ESP32)
- Уровень воды в баке: аналоговый или ультразвуковой датчик уровня (в зависимости от реализации)

### Фиксированная распиновка (ESP32)
- `GPIO21` -> I2C `SDA` (`BME280`, `BH1750`)
- `GPIO22` -> I2C `SCL`
- `GPIO27` -> датчик дождя `DO` (флаг дождя)
- `GPIO26` -> rain gauge (прерывание)
- `GPIO25` -> анемометр (прерывание)
- `GPIO34` -> флюгер (аналоговый вход, только input)
- `GPIO4` -> `DS18B20` data (OneWire)
- `GPIO35` -> датчик давления воды (аналоговый вход, только input)
- `GPIO32` -> датчик уровня воды в баке (аналоговый вход)
- `GPIO33` -> резервный GPIO

### Линии питания
- `3.3V` -> датчики/модули логики ESP32, где требуется 3.3V
- `5V` -> внешние датчики/модули, где требуется 5V
- `GND` -> общая земля всех подключенных модулей

### Ключи телеметрии (поле `readings[].pin` на сервере)
- `air_temperature`
- `air_humidity`
- `atm_pressure`
- `rain_detected`
- `rain_mm_hour` (или `rain_mm_total`, если выбран накопительный режим)
- `wind_speed`
- `wind_direction`
- `water_temperature`
- `light_lux`
- `water_pressure`
- `tank_level`

### Примечания
- Для импульсных датчиков (`GPIO25`, `GPIO26`) использовать прерывания.
- Для ADC-каналов (`GPIO34`, `GPIO35`, `GPIO32`) использовать фильтрацию/усреднение.
- Поддерживать калибровочные таблицы для:
  - направления ветра (диапазоны ADC -> румбы),
  - давления воды (ADC -> bar),
  - уровня бака (ADC/дистанция -> %).
- При использовании одного `BME280` не дублировать отдельные датчики температуры/влажности/давления на этом же узле.
